# 3D-BRPIF_instances-results

This repository contains intances and results for the $Three-Dimensional Block Relocation Problem with Item Families$ proposed and discussed in the Ph.D. thesis "Heuristics Approaches for the Three-Dimensional Block Relocation Problem with Item Families: Operations Research and Reinforcement Learning Perspectives" by Elisa Savio.

It contains 4 main folders:
- `Boge&Knust_dataset`, which contains instaces and results obtained for the Block Relocation Problem with Item Families proposed by [Boge and Knust (2023)](https://link.springer.com/article/10.1007/s00291-022-00703-x). Instances are also available at http://www2.informatik.uos.de/kombopt/data/brpif/.
- `Custom_dataset`, which contains a instances and results for a newly generated dataset. 
    - In the `Instances` folder, instances are divided in three classes, depending on the size: small (S), medium (M), and realistic (R). Each class contains 3 folders, one for each distribution: $RandomAssignment$, $Min1ItemFamily$, and $UniformAssignment$.

- `FeatureAnalysis_dataset`, which contains the 50 instances and results employed to perform the feature analysis aimed at identifying the useful features to describe the observation of the environment.
- `Lee&Lee_dataset`, which contains instances and results obtained for the Three-Dimensional Block Relocation Problem proposed by [Lee and Lee (2010)](https://www.sciencedirect.com/science/article/abs/pii/S0305054809002433?via%3Dihub).
